# Security policy

Please report suspected vulnerabilities privately through GitHub's security-advisory interface for this repository. Do not open a public issue for an undisclosed vulnerability.

Supported security work currently covers the repository, packaging, deterministic tools, and CI configuration for the unactivated candidate. There is no supported production runtime release yet.

Do not include secrets, access tokens, private project records, or personal data in a report or fixture. Maintainers will acknowledge a complete report when the project is actively staffed; no fixed response-time commitment is currently offered.
