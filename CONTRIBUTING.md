# Contributing

Wayfinder is contract-governed and evidence-sensitive. Please open an issue before changing semantics, package bytes, adapter behavior, certification policy, or activation status.

For ordinary repository changes:

1. Read `AGENTS.md` and the maintainer workflow.
2. Keep the change bounded and preserve unrelated bytes.
3. Run repository validation and the maintainer doctor.
4. Run focused conformance tests for the affected adapter or tooling.
5. Describe changed behavior, verification, and unavailable observations in the pull request.

Never regenerate, rewrite, or relabel accepted evidence. A governed-byte or semantic change requires an explicitly authorized candidate revision and replacement evidence rather than an in-place correction.

By contributing, you agree that your contributions are licensed under Apache-2.0.
