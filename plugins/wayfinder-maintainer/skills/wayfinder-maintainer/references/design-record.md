# Wayfinder design record

Maintainer-only history. [Record-store guide](design-record/README.md) explains the hierarchy and CLI.

`maintain.py record list` discovers records; `record read --id ID --history` reads a decision chain; `record add --input FILE` creates a new record.

[Current maintainer state](current-state.md) is the sole authority for current candidate, evidence, activation, and authorization. This page preserves legacy heading anchors; it is navigation, not a duplicate chronology.
